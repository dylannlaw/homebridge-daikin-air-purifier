# Start the 1.0 release line

## Summary

`package.json` (and `package-lock.json`) go from `0.2.0` to `1.0.0`, so the next release is published as `1.0.<run number>`.

## Why

Control through the Daikin cloud now works with the user's Daikin email and password, and HomeKit can choose the purifier's Eco, Pollen and Circulator modes and set the humidifier's strength. That's the first version that does what the plugin set out to do, so it starts a new major line.

## Design

Per `AGENTS.md` and `.github/workflows/release.yml`, only MAJOR.MINOR is changed and the patch stays at `.0`. CI takes `1.0` from `package.json`, adds its run number as the patch, and publishes that. So the first 1.x release on npm will be `1.0.<run number>`, not `1.0.0`. That's expected.

No settings were removed or renamed, so existing configs keep working.

## Files

- `package.json`, `package-lock.json`: version `1.0.0`.
